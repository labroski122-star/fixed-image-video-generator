# fixed-image-video-generator

Semplice web app Flask per unire un'immagine e un file audio in un video MP4 1080p con immagine fissa.

## Requisiti
- Python 3.8+
- FFmpeg installato nel path di sistema

## Installazione locale
1. Clona la repo
2. Crea virtualenv e installa dipendenze:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
